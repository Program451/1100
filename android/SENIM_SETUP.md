# Android Senim

Это исходный Android-проект из архива `role-play-guide (2).zip`. Для локальной debug-сборки требуется Gradle 9.3.1, JDK 21 и Android SDK 36.1. В архиве не было Gradle Wrapper; запускайте установленный Gradle командой `gradle assembleDebug`.

Для Firebase Cloud Messaging скачайте `google-services.json` для Android-приложения `com.aistudio.senim.hqkxpw` из проекта Firebase Senim и поместите его в `app/google-services.json` на своём компьютере. Файл исключён из Git. Без него push не будет настроен.

Сервер: `https://senim.studynesthub.com/`. Общий ключ доступа вводится в настройках приложения; не помещайте его в проект, коммиты или публичную сборку. Приватный ключ сервисного аккаунта Firebase принадлежит только серверу и никогда не должен попадать в APK или Git.

Для проверки нужны два телефона и разрешение на уведомления. Приложение поставляется как демо: не используйте настоящие банковские или персональные данные.
